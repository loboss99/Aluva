- ALUVA

Sitio web desarrollado para **ALUVA Outdoor**, emprendimiento dedicado a la venta de ropa de trabajo, Equipos de Protección Personal (EPP) y vestuario personalizado.

El proyecto fue desarrollado como parte de una evaluación académica, adaptando una plantilla web a la identidad visual y necesidades de ALUVA.

Objetivo

Desarrollar un sitio web funcional que permita presentar la empresa, sus productos y sus principales canales de contacto mediante una interfaz clara, responsive y coherente con la identidad visual de ALUVA.

 Secciones del sitio

- Inicio
- Productos
- Nosotros
- Contacto

 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Plantilla ASSAN como base para el desarrollo

Herramientas

- Símbolo del sistema de Windows (CMD) para la ejecución de comandos durante la configuración del proyecto.
- Git para control de versiones.
- GitHub para alojamiento del repositorio.
- Netlify para despliegue y publicación del sitio web.
